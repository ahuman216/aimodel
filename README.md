What your project is/does (and what it's called)
This project is called the Alzheimer's Disease Ai Predictor, and it takes images of brain mris, and detects if the individual has alzheimers, and if so, how much it has progressed.
This allows for interpretation of mris which are not easy to understand. 

Why you made your project
I made this project because I am interested in mris and AI models, so I wanted to do something to combine the two, and Alzheimer's disease datasets are easy to access.

How you made your project
I made this project using pytorch and other machine learning algorithms, and I used my knowledge of Flask from my last project to create a web application that allows users to upload a scan to interpret.
I created web templates as well as multiple versions of the model, and I had to adjust the parameters and train it on a dataset that was approximately 6000 images big; then I would test it and measure accuracy.
This process continued until I reached a 64% accuracy rate, which is when I decided to stop. 

What you struggled with and what you learned
I especially struggled with learning how to train a model, as well as a lot of OneDrive and file errors along the way. Also deploying this was extremely difficult due to the large size of my multiple trained models.
Due to this, I had to continue switching platforms over and over until I found something that worked.
